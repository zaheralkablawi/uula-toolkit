أداة UULA Toolkit لبرنامجي PowerPoint وWord (ويندوز)
=====================================================
كل أدوات علا في إضافة واحدة: Restyle وArabic Math وGraph وDark وCover.

التثبيت:
1) فك ضغط هذا الملف (Extract All).
2) شغّل الملف UULA-Toolkit-Setup.exe (دبل كلك).
   إذا ظهرت رسالة Windows protected your PC: اضغط More info ثم Run anyway.
3) أغلق PowerPoint وWord تمامًا ثم افتحهما من جديد.
4) في تبويب UULA Toolkit: زر UULA Toolkit (قائمة الأدوات) وزر لكل أداة يفتحها في نافذة خاصة بها، فتفتح أكثر من أداة معًا.
   إذا لم يظهر: Insert ← Add-ins ← My Add-ins ← Developer Add-ins.

إذا منع الويندوز ملف exe: شغّل Install-UULA-Toolkit.cmd بدلًا منه.

التحديثات والأدوات الجديدة تصل تلقائيًا، لا حاجة لإعادة التثبيت.
للإزالة: شغّل الـ exe مرة ثانية واختر "لا"، أو شغّل Uninstall-UULA-Toolkit.cmd.

المتطلبات:
- Microsoft 365 (PowerPoint وWord) محدّث.
- خط UULA Sans مثبّت على الجهاز.
- اتصال بالإنترنت.

------------------------------------------------
UULA Toolkit for PowerPoint and Word (Windows)
1) Extract the zip.  2) Run UULA-Toolkit-Setup.exe (if SmartScreen appears: More info > Run anyway).
3) Restart PowerPoint and Word. The button is on the UULA Toolkit tab (or Insert > Add-ins > My Add-ins > Developer Add-ins).
If the exe is blocked, run Install-UULA-Toolkit.cmd. Updates and new tools arrive automatically.
Needs an up-to-date Microsoft 365, the UULA Sans font and internet access.
